# Parcours guidés — le flux, service par service

**Pour qui :** un nouvel utilisateur qui veut comprendre **comment le travail circule** dans l'ERP.
**Comment c'est écrit :** chaque service, **dans l'ordre du flux d'une affaire**, étape par étape :
**⬅️ Avant** (ce qui s'est passé en amont) → **📝 Ici** (l'écran avec le formulaire ouvert et ses cases expliquées) → **➡️ Ensuite** (où part le travail).

| Ordre | Service | Ce qu'on y fait |
|---|---|---|
| [01](01-commercial.md) | **Commercial** | Demande client → DT (n° d'affaire) → offre → commande · avoirs & commandes P |
| [02](02-be.md) | **Bureau d'Études** | Nomenclature, gamme, chiffrage du prix de revient |
| [03](03-achats.md) | **Achats** | Demandes de prix, DA, bons de commande fournisseurs |
| [04](04-production.md) | **Production** | Planning, BDT, sous-traitance, soldage au PIN |
| [05](05-oas.md) | **OAS** | Traitement de surface : balancelles, bains, relevés |
| [06](06-qualite.md) | **Qualité** | PV, NC, 8D, dérogations, libération des lots, retours clients |
| [07](07-securite.md) | **Sécurité (HSE/RSE)** | DUER, accidents, EPI, chimie, ATEX, VGP |
| [08](08-expeditions.md) | **Expéditions** | Réceptions, BL clients (partiels), transport |
